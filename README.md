# Cutie-Loader

A clean and simple Windows injector interface.

## Features
- ImGui-based menu interface
- Embedded resource loading
- Manual map injection engine

## Build Instructions
Run `Build.bat` or open `Cutie-Loader.sln` in Visual Studio 2022 and build with Release x64 configuration.

## Requirements
- Visual Studio 2022 (MSVC v143)
- Windows SDK
- Direct3D 9 SDK
